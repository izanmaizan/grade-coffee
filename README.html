⚙️ Setup & Menjalankan

1

Clone / Ekstrak Proyek

Buka PowerShell atau Command Prompt, lalu clone repo:

powershell 
git clone <url-repo>
cd grade-coffee

Atau ekstrak ZIP ke folder pilihan, lalu buka terminal di dalam folder tersebut.

2

Buat File .env

Buat file bernama .env di folder root proyek (sejajar dengan docker-compose.yml), isi dengan:

.env 
APP_ENV=development

DB_NAME=green_bean_grading
DB_USER=root
DB_PASSWORD=

CORS_ORIGINS=http://localhost:8080
ℹ️
File .env sudah tersedia di repo. Cukup pastikan isinya sesuai dengan di atas.
3

Pastikan Model Ada

Pastikan file backend/weights/best.pt tersedia di dalam folder proyek.

⚠️
Jika file best.pt tidak ada, backend tidak bisa melakukan deteksi. Minta file dari tim atau jalankan training terlebih dahulu.
4

Jalankan Docker

Pastikan Docker Desktop sudah terbuka, lalu jalankan perintah berikut di terminal:

powershell 
docker compose up --build

Docker akan otomatis:

  • Mendownload image MySQL, Python, Node.js, Nginx
  • Build image backend dan frontend
  • Menjalankan migrasi database otomatis
  • Menyalakan semua service
⏱️
Build pertama kali membutuhkan waktu 5–15 menit tergantung kecepatan internet. Build berikutnya jauh lebih cepat karena cache.
5

Buka Aplikasi

Setelah semua service berjalan (tidak ada error merah di terminal), buka browser:

🔧 Perintah Docker Berguna

Menghentikan Aplikasi

powershell 
docker compose down

Reset Total (hapus database)

powershell 
docker compose down -v

Jalankan Ulang (tanpa build ulang)

powershell 
docker compose up

Lihat Log Realtime

powershell 
docker compose logs -f

Perbarui Model (setelah training baru)

Salin best.pt hasil training ke folder backend/weights/, lalu rebuild backend:

powershell 
docker compose up --build backend

🧠 Training Model YOLOv8 (Opsional)

Lakukan ini hanya jika ingin melatih ulang model dengan dataset baru. Tidak diperlukan untuk menjalankan aplikasi — cukup gunakan best.pt yang sudah ada.

⚠️
Training tidak berjalan di dalam Docker. Jalankan langsung di Windows dengan Python.

1. Install Python & Dependencies

powershell 
python -m venv venv
venv\Scripts\activate
pip install -r training\requirements.txt

2. Jalankan Training

powershell 
python training\train.py --data training\data.yaml --epochs 100
FlagDefaultKeterangan
--epochs100Jumlah epoch training
--batch16Kurangi ke 8 jika RAM terbatas
--deviceautocpu / cuda / 0
--modelyolov8n.ptPakai last.pt untuk lanjut training

3. Salin Model ke Backend

powershell 
copy runs\detect\green_bean\weights\best.pt backend\weights\best.pt

🧪 Troubleshooting

Docker Desktop tidak bisa dibuka / WSL error ▶
Pastikan WSL 2 sudah aktif. Buka PowerShell sebagai Administrator dan jalankan:

wsl --install

Lalu restart PC dan buka Docker Desktop kembali.
Error: port is already allocated (8080 atau 8000) ▶
Port tersebut digunakan aplikasi lain. Cari dan tutup prosesnya lewat Task Manager, atau ubah port di docker-compose.yml:

ports: - "9080:80" → lalu akses di localhost:9080
Backend restart terus-menerus (keeps restarting) ▶
Cek file .env, pastikan:

APP_ENV=development

Jika diisi production, backend akan menolak CORS dengan domain localhost.
Model best.pt tidak ditemukan / detection error ▶
Pastikan file backend/weights/best.pt ada. File ini tidak dibuat otomatis — harus disalin dari hasil training atau diminta dari tim.
Database error / tabel tidak ditemukan ▶
Reset total dengan menghapus volume lama:

docker compose down -v
docker compose up --build
Build sangat lambat atau stuck ▶
Wajar saat pertama kali — Docker mendownload banyak image dan menginstall dependencies. Biarkan sampai selesai. Build berikutnya akan jauh lebih cepat karena layer cache.
